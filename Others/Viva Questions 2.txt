1. What is Vue?
A progressive JavaScript framework for building reactive, component-based UIs.

2. What is a reactive framework?
A framework where UI automatically updates when the underlying data changes.

3. What is memoization?
An optimization technique that caches function results based on input arguments.

4. What is a rainbow table?
A precomputed table of hashes used to reverse passwords. Mitigated by salting.

5. What is v-cloak?
A Vue directive to hide raw template code until Vue finishes rendering.

6. How can you access the server without a browser/URL?
Using cURL, Postman, SSH, or tools like Telnet/Netcat.

7. v-if vs v-show?

v-if: Adds/removes element from DOM.

v-show: Keeps element in DOM, toggles visibility with CSS.

8. Memoization vs caching?

Memoization → caches function results.

Caching → general concept, stores any data for reuse.
